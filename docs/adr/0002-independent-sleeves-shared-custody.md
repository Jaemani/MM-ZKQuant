# 독립 전략 지분과 공동 보관을 분리한다

사용자가 승인한 Concept Specification v0.2에 따라 투자 상품의 단위를 공동 합성 펀드에서 Strategy Sleeve로 바꾼다. 투자자는 전략을 직접 선택하며, 각 전략의 alpha·자본·주문·체결·지분·비용·손익은 독립적으로 귀속된다. 하나의 Omnibus Vault는 실제 자산 보관과 실행만 공유한다.

기존 Pilot의 공동 지분, provider alpha 합성, actor Shapley 보상, 자동 provider 가중치는 이 새 제품의 회계로 재사용하지 않는다. 기존 테스트넷 계약과 자금은 이전 모델의 실행 기록으로 보존하며, 새 장부에 자동 이관하거나 기존 shadow 성과를 실제 전략 지분가치로 바꾸지 않는다.

가장 중요한 수용 조건은 `VaultEquity = Σ StrategyEquity + ProtocolAccruals`와 전략 내부 투자자 권리·제공자 보수의 대사다. 공동 보관 자체는 손실 격리를 보장하지 않으므로 전략의 가용 자본을 넘는 주문과 다른 전략의 현금을 이용한 출금은 거절해야 한다. TEE를 제외한 검토 환경의 운영자는 비공개 장부를 읽을 수 있으며, 이를 운영자에게도 비공개라고 표시하지 않는다.
