## 진행 중인 ZK 실험

목표는 운용자 서명이 맞아도 잘못된 Book 장부 변경은 거부됨을 실제 회로·Solidity verifier·외부 DEX 포크로 검증하는 것입니다.

- 두 Book의 현금·자산·예약 금액·운용자 제출 순서·공개키를 비공개 상태에 포함합니다.
- 운용자 서명 확인, 자금 예약, 실제 체결에 따른 정산을 나눕니다.
- 다른 Book으로 자산을 옮기면서 전체 합계만 맞추는 반례를 검사합니다.
- 실제 수령량은 Vault가 거래 전후 잔액으로 확인합니다. 임의 수치로 만든 proof도 실제 실행 기록과 다르면 정산하지 않습니다.
- 실제 TEE에서의 witness/proving은 별도 인수 항목입니다.

개발 중인 회로는 전체 프로토콜 완성이 아닙니다. 최초 Book 배정은 신뢰된 테스트 초기 상태이며 투자자 지분 증명이 아닙니다. 연구용 운용자 서명 키는 기존 지갑 등록과 아직 연결하지 않았습니다. 목표 포지션에서 주문을 계산하는 증명도 이후 작업입니다.

로컬 단독 Groth16 setup은 연구용입니다. 실자금 검증키로 사용하지 않습니다. 연구용 Vault는 chain ID 31337에서만 배포되도록 제한합니다.

## 필요한 결정과 결과 기록

현재 코드·문서 작업에는 추가 정보가 필요하지 않습니다. 첫 TEE 실험의 후불 해제와 최대 $2 사용은 승인받았습니다. 새 API/배포 권한이 필요하면 목적과 범위를 구체적으로 확인합니다. 키를 채팅이나 저장소로 전달하지 않습니다.

경제조건 미정 목록과 인수 기준은 [팀 개발명세](team-development.md)를 따릅니다. 새 검사 성공 전에는 PASS로 표시하지 않습니다. 환경·체인·코드/회로 버전·실 하드웨어 여부·외부 송신 여부를 기록합니다. 기존 109개 회귀 테스트와 외부 포크 16개 검사는 새 명세 인수와 합치지 않습니다.
