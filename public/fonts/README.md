# Font provenance

`britti-sans-variable.woff2` is the Britti Sans variable webfont used by the official Monad brand kit, fetched on 2026-10-06 from:
https://www.monad.xyz/_next/static/media/e4f97a545f31e4e6-s.p.woff2

Reference and role assignment: https://www.monad.xyz/brand-and-media-kit
- Britti Sans: headlines and titles (100–900, normal).
- Inter: body and paragraphs.
- Roboto Mono: labels, buttons, links, code and decoration.

Inter, Roboto Mono and the Korean fallback Noto Sans KR load through the Google Fonts stylesheet in index.html. Britti Sans is served locally and preloaded. The font binary is unmodified; its ownership is not transferred by this repository.
